# Progression Tuning for Kronos client - rc1.1

## What's new

- Reticle challenges now pop up when you finish a tier, using the game's own reticle card.
- Reticles stay locked until you've earned them through their challenge. Default reticles are always available.
- Weekly challenge popups only show when the game says the weekly is actually done, so no more false popups when the week rolls over.
- Master prestige weapon levels now follow the game's own pacing: 1,800 XP per level, up to level 250.

## Under the hood

- Client hook build 29: removed an unused log reader. Nothing changes in play.

## Known gaps

- Reticle locks were checked on the Zombies tab. The Shared tab may still list locked reticles.

Same as rc1.0 - see INSTALL.txt in the zip.
